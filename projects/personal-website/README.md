# 🌐 Personal Website

A one-page portfolio site built with plain HTML, CSS and JavaScript.

**Features:** a typing-effect hero, a dark/light toggle that remembers your choice, a mobile menu, filterable project cards, a Codédex Builds timeline, scroll-reveal animations (turned off for anyone who prefers reduced motion) and a nav link that highlights the section you're viewing.

## Make it yours
Search `index.html` for these placeholders and replace them:
- `Your Name` and the `YN` logo
- the About paragraphs and the avatar emoji
- `you@example.com` and the LinkedIn URL

Colors are CSS variables at the top of `style.css`. Change `--accent` to restyle the whole site.

## Run / deploy
Open `index.html` in a browser, or run `python3 -m http.server` in this folder.
To publish it for free, turn on **GitHub Pages** in the repo settings, or drag the folder onto Netlify.
