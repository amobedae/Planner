# Projects

Four standalone builds. Each folder has its own README with setup steps.

| Project | Language | What it does |
|---|---|---|
| [☕ Cafe Finder](cafe-finder/) | JavaScript | Finds cafes near you on a map, using live Google Maps data (or free OpenStreetMap data when you have no API key) |
| [🎙️ Voice Virtual Assistant](voice-assistant/) | Python | Talk out loud: ElevenLabs handles speech-to-text and text-to-speech, and Claude writes the replies |
| [📚 Amazon Bestsellers Analysis](amazon-bestsellers/) | Python | Uses pandas to analyze Amazon's Top 50 bestselling books from 2009 to 2019 and saves the charts |
| [🌐 Personal Website](personal-website/) | HTML/CSS/JS | A responsive portfolio site with a dark mode that links to all of these projects |
