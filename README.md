# Planner

## Weather App

A simple weather app built with plain HTML, CSS, and JavaScript. Search for
any city or use your current location to see current conditions and a
5-day forecast. Weather data comes from the free [Open-Meteo](https://open-meteo.com/)
API (no API key required).

### Running locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser.
